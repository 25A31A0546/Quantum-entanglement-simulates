# Quantum-entanglement-simulates
This is an interactive simulator that shows quanatum entanglement(link) between 
paricles.If we measure one that instantly difines the state of other
no matter the distance.

# What is this?
Quantum entanglement is one of the mind blowing circumstance in physics
when two particles become entangled,the state of one instantaniously infuencces 
the other,regardless how far they are.
Through this you can
* Create pairs of entangled quantum particles
* Observe their superposition states(spin up or spin down) before the
  measurement.
* Collapse the Wave Function of one particle and watch its partner
  responds in the same time.
* Simulate multiple entangled paires in parallel.

# Technologies Used
**Python** — Core language for quantum gate simulation and matrix calculations
 **NumPy** — Handles Hadamard and CNOT gate matrix operations using numpy.kron()
 **Flask** — Lightweight web framework that serves the simulation as a REST API
 **HTML/CSS/JavaScript** — Frontend circuit diagram, animations, and probability bar visualizations
 **Google Fonts** — Share Tech Mono and Rajdhani fonts for the UI styling(for visual styling)
